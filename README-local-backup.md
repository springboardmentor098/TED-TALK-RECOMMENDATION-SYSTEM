# Personalized TED Talks Recommendation System Using Machine Learning

## Project Overview

This project aims to develop a personalized TED Talks recommendation system using machine learning and natural language processing techniques.

## Objectives

* Collect and inspect a suitable TED Talks dataset.
* Explore and preprocess textual data.
* Develop a content-based recommendation system.
* Recommend TED Talks based on content similarity.

## Technologies

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* Jupyter Notebook
* Scikit-learn

## Dataset

**Name:** TED Ultimate Dataset
**Source:** [Kaggle – TED Ultimate Dataset](https://www.kaggle.com/datasets/miguelcorraljr/ted-ultimate-dataset)

The original downloaded dataset files will be stored in `data/raw/`.

## Project Structure

* `data/raw/` — Original dataset files
* `data/processed/` — Processed dataset files
* `notebooks/` — Data exploration and experiments
* `requirements.txt` — Python dependencies
